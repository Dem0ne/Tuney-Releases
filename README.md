# Tuney downloads

Official Windows customer installers. Application source is maintained in a private repository.

Download the installer from [Releases](https://github.com/Dem0ne/Tuney-Releases/releases). For version 0.4.5, choose **TuneySetup-0.4.5.exe**. You do not need to download the automatically generated source ZIP or TAR files.

Version 0.4.5 is a **customer test prerelease**. It has been verified on the developer's Windows PC; a fresh-PC installation/reboot test and a complete original-mixer-preset comparison remain outstanding.

See the release's INSTALL.md for installation steps. Windows x64 and administrator permission are required. Profile processing requires a Tuney account and activation.
